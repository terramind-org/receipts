# receipts

The data, images and artifacts behind what Terramind publishes. If a post makes a claim, what it rests on is here.

- `blog/` — one folder per post on [terramind.com/blog](https://terramind.com/blog): the raw results, the images, and whatever else a post's numbers came from.
- `projects/` — open artifacts from Terramind projects.
